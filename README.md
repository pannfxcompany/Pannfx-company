# PANNFX COMPANY — Website Prototype V1

Prototype front-end responsif bertema premium hitam dan silver.

## Isi
- `index.html` — struktur halaman
- `styles.css` — desain desktop dan mobile
- `script.js` — menu mobile dan formulir demo

## Cara melihat
Buka `index.html` di browser. Koneksi internet dibutuhkan untuk memuat font Google Fonts; website tetap memakai font fallback jika font tidak tersedia.

## Penting
Ini masih prototype front-end. Formulir tidak mengirim data ke server, dan belum ada autentikasi, database, dashboard admin, atau sistem partner yang sesungguhnya. Jangan mengumpulkan data pribadi pengguna melalui versi demo ini.

## Langkah publikasi yang disarankan
1. Buat repository GitHub pribadi dan unggah ketiga file front-end.
2. Impor repository ke Vercel atau layanan hosting statis sejenis.
3. Uji semua halaman di ponsel dan desktop.
4. Beli `pannfx.com` setelah ketersediaannya diperiksa, lalu hubungkan melalui pengaturan domain di hosting.
5. Sebelum membuka registrasi, bangun backend untuk autentikasi, database, role akses, validasi server, kebijakan privasi, dan perlindungan spam.
6. Tambahkan konten resmi dan tinjau semua klaim/ketentuan partner sebelum peluncuran.
